# Nunito

Fonte variável de peso distribuída com o app, incluindo uso offline.

Origem: https://github.com/google/fonts/tree/main/ofl/nunito
Arquivo original: `Nunito[wght].ttf` (renomeado para `Nunito.ttf`).
Licença SIL Open Font License 1.1: [OFL.txt](OFL.txt).

Os arquivos Regular (400), SemiBold (600) e Bold (700) foram gerados com FontTools a partir do eixo `wght` da fonte original, sem alteração dos desenhos. O app declara esses pesos explicitamente.
